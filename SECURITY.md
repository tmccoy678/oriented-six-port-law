# Security and disclosure boundary

The P = NP algorithm-search program states that any genuine polynomial-time
algorithmic hit is held under its isolation rule.

Accordingly:

1. finite-law proofs and non-sensitive search measurements may be public;
2. credentials, lease tokens, private lineage artifacts, raw protected output,
   and unpublished candidate proof objects remain private;
3. a protected hit travels only through the platform's official submission and
   isolation path; and
4. public status changes only after an accepted checker record authorizes it.

This repository is an attribution and reproducibility record, not a channel
around the protected review process.
